Token Radar ranks pre-token protocols by the implied value of the token they may one day issue, from a sealed DefiLlama snapshot: TVL, seven-day growth, age with no token, chain reach and a stated category prior — no hand-kept list of names. Every row carries a six-step farm plan with costs and times, a signal-strength score for how much of the record exists, and the dashboard adds a model sandbox that re-ranks the board live from the same function.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
